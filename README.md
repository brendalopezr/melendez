# MELENDEZ Mobiliario

Landing corporativa premium para una empresa de diseño, fabricación e instalación de muebles en melamina.

## Concepto visual

“Atelier técnico”: fotografía arquitectónica cálida, retícula editorial, contraste grafito/marfil y recursos inspirados en planos de fabricación. La paleta usa `#171714`, `#f3f0e9`, nogal `#a87b4f` y cobre `#c29662`. Playfair Display aporta carácter editorial y Manrope claridad funcional.

## Uso

Abre `index.html` directamente o inicia el proyecto con Live Server. No requiere compilación ni dependencias locales. Internet solo es necesario para Google Fonts y Bootstrap Icons.

## Estructura

- `index.html`: contenido semántico, SEO y componentes.
- `css/styles.css`: sistema visual, responsive y animaciones.
- `js/main.js`: navegación, reveal, filtros, lightbox, slider, contadores y formulario.
- `img/`: imágenes creadas específicamente para este concepto.

## Personalización antes de publicar

Reemplaza el teléfono `51999999999`, el correo, la ciudad, enlaces sociales y datos legales. El formulario valida los datos y prepara el pedido en WhatsApp; para guardar solicitudes en una base de datos se requiere conectar un backend.

Las imágenes incluidas son recursos temporales originales generados para la maqueta y pueden sustituirse por fotografías de proyectos reales conservando los mismos nombres o actualizando las rutas.
